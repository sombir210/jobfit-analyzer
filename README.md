# JobFit Analyzer

## 📌 Project Overview
JobFit Analyzer is a web-based Resume Analysis and Job Recommendation System.
It analyzes a candidate’s resume and determines suitability for different job domains
such as Technical, Telecom, and Non-Technical roles.

## 🚀 Features
- Resume upload and text analysis
- Skill extraction from resumes
- Job suitability scoring
- Domain-based job recommendations
- Clean and responsive user interface

## 🛠️ Technologies Used
- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (Backend & Database)
